How a question is shown

  1. If stem and options are complete encoded text, that is the question. No scan of the same wording.
  2. A figure (PNG / base64) is shown only when the paper has a spectrum or option diagram. Text that is already in that image is not repeated.
  3. When A–D live in the figure, letter buttons select them. When A–D are encoded text, those texts are the selectable options.

Learn-by-solve

Follow-ups are authored offline (Astra harness, schema-checked) and served as JSON. The student never sees the misconception type. Runtime does not call a model.
